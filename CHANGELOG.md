# Changelog

## 0.0.3 (2026-11-16)

- Seventh accounting variant M6: M2 with forgetting (exponential regression weights TAU_W = 20 s, decaying lower bound TAU_F = 30 s).
- Script `scripts/sensitivity_m6.py` and results for the sensitivity of M6 to TAU_F; updated `results/runs.csv` and summaries.
- Tag v0.0.2 on GitHub contained the package numbered 0.0.1. Version 0.0.3 aligns the tag, the package and PyPI.

## 0.0.1 (2026-11-13)

- First release: simulation of a guest OS with OOM kills between monitoring points.
- Six accounting variants M0–M5 (`sydost_oom_bench.METHODS`).
- Experiment script, figure script, PyPI audit script and tests.
- Documentation in Russian and English, citation file, MIT license.
