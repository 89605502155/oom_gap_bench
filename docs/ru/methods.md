# Варианты учёта отказов (M0–M5)

Все варианты реализованы одним контроллером `sydost_oom_bench.methods.Controller`. Каждый вариант задаётся набором флагов `Method`.

- **M0** – исходный алгоритм: мгновенное значение занятой памяти, регрессия по пяти точкам, интервал по числу перераспределений за пять циклов.
- **M1** – приращение счётчика `oom_kill` переводит систему в нестабильный режим на пять циклов.
- **M2** – M1 плюс пересчёт выборки: объём завершённого процесса добавляется к наблюдению, точка цензурирована, нижняя граница потребности удерживается `FLOOR_HOLD = 60` с.
- **M3** – пик за интервал вместо мгновенного значения; пик у выделенного объёма считается цензурированным.
- **M4** – M3 с запасом по квантили 0,9 и ограничением интервала временем исчерпания запаса.
- **M5** – M2 с агентом событий: внеплановая точка при свободной памяти ниже 256 МиБ и росте быстрее 20 МиБ/с.

Параметры по умолчанию: `R = 100` МиБ, `THRESH = 10` МиБ, `DT_MIN = 1` с, `DT_MAX = 10` с, `WINDOW = 5`.
